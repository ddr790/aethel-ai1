# Aethel Awwwards Creative Web Engine

Use `/Awwwards <brief>` in the Aethel chat. The command routes the request to the local Agent and expands a short brief into a creative-web build process.

The Agent is instructed to create an original concept, AWWWARDS_BRIEF.md, responsive UX/UI, motion, GSAP/ScrollTrigger interactions, optional 3D/WebGL/model-viewer, accessibility and performance safeguards, then iterate through code/visual QA before packaging the project ZIP.

This targets a high-end award-style quality bar; it does not guarantee an award or reproduce any specific site's design.
