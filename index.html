O cérebro do Aethel

Uma arquitetura feita para trabalhar em conjunto.

O Aethel combina o núcleo local com modelos de linguagem e ferramentas especializadas. A interface apresenta essa arquitetura como um sistema único, em vez de esconder como cada capacidade participa do trabalho.

AETHEL CORE

Local-first. Modular. Extensível.

O núcleo pode cuidar de ferramentas especializadas enquanto um modelo local assume tarefas de linguagem mais abertas. Isso permite evoluir o Aethel sem reconstruir o workspace.

✓ Raciocínio e matemática
✓ Especialistas de código
✓ Modelo local via Ollama
✓ Ferramentas de imagem e arquivos
✓ Camada de Agent para projetos

Agent Workspace

Da ideia ao projeto funcionando.

O Agent foi pensado para transformar uma solicitação em um fluxo de trabalho: entender, planejar, construir, verificar e entregar. A execução real depende das ferramentas e permissões disponíveis no ambiente.

Um fluxo, várias etapas.

Em vez de limitar o Aethel a uma resposta de texto, o workspace pode organizar tarefas de projeto em etapas claras.

01 Entender o objetivo
02 Criar um plano
03 Construir arquivos
04 Testar e corrigir
05 Entregar o projeto
$ aethel agent --project banana-site
