# Política de Privacidade — modelo para revisão

Este arquivo é um modelo técnico. Antes de publicar, substitua os campos genéricos pelos dados legais reais da entidade responsável pelo Aethel e revise com orientação jurídica adequada.

- Identifique o controlador/responsável pelo serviço.
- Explique quais dados de conta, uso, mensagens, arquivos e pagamentos são coletados.
- Explique finalidade, base legal, retenção e exclusão.
- Informe provedores de infraestrutura e pagamentos.
- Informe como o usuário exerce seus direitos aplicáveis.
- Publique uma versão acessível por URL HTTPS.
